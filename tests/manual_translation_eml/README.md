# 다국어 번역 경로 수동 확인용 EML

이 폴더의 메일은 정확도 평가 자료나 학습 자료가 아닙니다. 로컬 번역 모델이 여러 언어의 제목과 본문을 한국어 문맥 입력으로 변환하는지 GUI에서 확인하기 위한 안전한 실행 예제입니다. 모든 링크는 실제 접속 대상이 없는 `.example` 예약 도메인을 사용합니다.

각 파일을 GUI에서 분석한 다음 `엔진별 근거`의 `본문 문맥 ML` 행을 확인합니다. `문맥 입력: <언어 코드> → 한국어 로컬 번역`이 표시되면 번역 경로가 실행된 것입니다.

- `english_suspicious.eml`: 영어 계정 확인 유도 문맥
- `german_suspicious.eml`: 독일어 계정 확인 유도 문맥
- `french_suspicious.eml`: 프랑스어 계정 확인 유도 문맥
- `spanish_suspicious.eml`: 스페인어 계정 확인 유도 문맥
- `japanese_suspicious.eml`: 일본어 계정 확인 유도 문맥
- `arabic_suspicious.eml`: 아랍어 계정 확인 유도 문맥

이 예제의 최종 판정은 번역 품질이나 실제 탐지 정확도를 입증하지 않습니다. 번역 실행 여부와 분석 파이프라인 연결만 확인합니다.
